SuperPix SP1405 camera sensor

Required properties:
- compatible: "superpix,sp1405" or "ovti,ov9732"
- reg: I2C address
- clocks: the 24 MHz sensor clock
- clock-names: "xvclk"
- reset-gpios: sensor reset GPIO
- port: one output port containing an endpoint, as described by
  Documentation/devicetree/bindings/media/video-interfaces.txt
- data-lanes: <1> in the endpoint

Optional properties:
- pwdn-gpios: sensor power-down GPIO
- clock-lanes: <0> in the endpoint; defaults to 0
- lane-polarities: <0 0> in the endpoint; defaults to normal polarity
- clock-noncontinuous: endpoint flag for a non-continuous CSI-2 clock;
  the default is a continuous clock
- bus-type: <0> in the endpoint; defaults to automatic bus detection

Example:

	camera-sensor@36 {
		compatible = "superpix,sp1405";
		reg = <0x36>;
		clocks = <&sensor_clk>;
		clock-names = "xvclk";
		reset-gpios = <&gpio0 13 GPIO_ACTIVE_LOW>;

		port {
			endpoint {
				clock-lanes = <0>;
				data-lanes = <1>;
			};
		};
	};
