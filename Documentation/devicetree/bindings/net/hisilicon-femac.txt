Hisilicon Fast Ethernet MAC controller

Required properties:
- compatible: should contain one of the following version strings:
	* "hisilicon,hisi-femac-v1"
	* "hisilicon,hisi-femac-v2"
	and the soc string "hisilicon,hi3516cv300-femac" or
	"hisilicon,hi3520dv100-femac" (Hi3520D V100 up port, with the global
	register region as the second reg entry).
- reg: specifies base physical address(s) and size of the device registers.
  The first region is the MAC core register base and size.
  The second region is the global MAC control register.
- interrupts: should contain the MAC interrupt.
- clocks: A phandle to the MAC main clock.
- resets: should contain the phandle to the MAC reset signal(required) and
	the PHY reset signal(optional).
- reset-names: should contain the reset signal name "mac"(required)
	and "phy"(optional).
- phy-mode: see ethernet-controller.yaml [1].
- phy-handle: see ethernet-controller.yaml [1].
- hisilicon,phy-reset-delays-us: triplet of delays if PHY reset signal given.
	The 1st cell is reset pre-delay in micro seconds.
	The 2nd cell is reset pulse in micro seconds.
	The 3rd cell is reset post-delay in micro seconds.

The MAC address is not read from the hardware. The driver takes it from the
first of these that holds a valid address (all-zero values are ignored):
"mac-address" and "local-mac-address" (defined by ethernet-controller.yaml[1],
usually filled in by the boot loader through an ethernetN alias), the obsolete
"address" property (read by the OF core, not part of the schema), an NVMEM cell
named "mac-address" ("nvmem-cells" and "nvmem-cell-names", also defined by
ethernet-controller.yaml[1]). If none of them gives a valid address the driver
uses a random one and warns. An NVMEM provider that is not registered yet
defers the probe.

[1] Documentation/devicetree/bindings/net/ethernet-controller.yaml

Example:
	hisi_femac: ethernet@10090000 {
		compatible = "hisilicon,hi3516cv300-femac","hisilicon,hisi-femac-v2";
		reg = <0x10090000 0x1000>,<0x10091300 0x200>;
		interrupts = <12>;
		clocks = <&crg HI3518EV200_ETH_CLK>;
		resets = <&crg 0xec 0>,<&crg 0xec 3>;
		reset-names = "mac","phy";
		phy-mode = "mii";
		phy-handle = <&phy0>;
		hisilicon,phy-reset-delays-us = <10000 20000 20000>;
	};
